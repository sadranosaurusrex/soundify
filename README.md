# Soundify (اپلیکیشن استریم آنلاین موسیقی)

پروژه آزمون میان‌ترم برنامه‌نویسی Flutter برای پیاده‌سازی یک پلتفرم استریم و پخش آنلاین موسیقی مشابه Spotify با پشتیبانی از احراز هویت دو مرحله‌ای، امنیت بیومتریک، سرویس پخش صوت پس‌زمینه و رابط کاربری مدرن دارک و راست‌چین (RTL).

---

## 🌟 ویژگی‌ها و قابلیت‌های پیاده‌سازی‌شده

### ۱. احراز هویت و امنیت (Authentication & Security)
- **ثبت‌نام و ورود:** فرم‌های ثبت‌نام و ورود با اعتبارسنجی کامل ورودی‌ها (ایمیل، رمز عبور حداقل ۸ نویسه، نام کاربری و نام نمایشی).
- **ورود با کد یکبار مصرف (OTP):** ارسال کد ۶ رقمی به ایمیل، تایید حساب و تایمر معکوس ۶۰ ثانیه‌ای برای ارسال مجدد.
- **بازیابی رمز عبور:** فرآیند دو مرحله‌ای درخواست کد بازیابی به ایمیل و ثبت پسورد جدید.
- **مدیریت امن نشست (Session Management):**
  - ذخیره‌سازی امن `Access Token` و `Refresh Token` با استفاده از `flutter_secure_storage` و عدم ذخیره به صورت متن ساده در SharedPreferences.
  - مکانیزم خودکار تمدید توکن منقضی‌شده با `QueuedInterceptorsWrapper` در `Dio` در صورت دریافت خطای ۴۰۱ بدون خروج ناخواسته کاربر.
- **ورود بیومتریک (Biometrics):** پشتیبانی از حسگر اثر انگشت و اسکن چهره با پکیج `local_auth`.
- **بررسی یکپارچگی و امنیت دستگاه:** بررسی وضعیت امنیتی دستگاه (شناسایی دسترسی Root و تشخیص شبیه‌ساز Emulator) و نمایش وضعیت در صفحه پروفایل.

### ۲. وب‌سرویس و شبکه (Networking & API)
- پیاده‌سازی کلاینت شبکه یکپارچه با `Dio` شامل Base URL سرور (`https://soundify.easyfound.ir/api/v1`)، مدیریت زمان‌بندی (Timeout) و تبدیل خطاهای سرور به پیام‌های فارسی خوانا.
- **کاتالوگ آهنگ‌ها:** دریافت لیست قطعات منتخب (Featured) و کل کاتالوگ با عنوان، نام خواننده، آلبوم، مدت زمان و کاور.
- **جست‌وجوی آنلاین با Debounce:** جست‌وجوی زنده آهنگ‌ها و خوانندگان همراه با مکانیزم تاخیر ۵۰۰ میلی‌ثانیه‌ای جهت بهینه‌سازی ترافیک سرور.
- **علاقه‌مندی‌ها (Favorites):** لایک و آن‌لایک سریع قطعات و هماهنگ‌سازی آنی با سرور.
- **مدیریت کامل پلی‌لیست‌ها (CRUD):**
  - مشاهده پلی‌لیست‌های اختصاصی کاربر
  - ایجاد، ویرایش نام و توضیحات و حذف پلی‌لیست
  - افزودن آهنگ به پلی‌لیست از دیالوگ منوی قطعات و حذف آهنگ از درون پلی‌لیست
- **مدیریت وضعیت‌های شبکه:** مدیریت صحیح حالت‌های لودینگ (Loading Indicator)، صفحه خالی (Empty View) و خطای اتصال با دکمه تلاش مجدد (Retry).

### ۳. پخش موسیقی و سرویس پس‌زمینه (Audio & Background Service)
- **استریم آنلاین صوت:** پشتیبانی کامل از پروتکل HTTP Range (206 Partial Content) سرور.
- **کنترل‌های کامل پخش:** دکمه‌های Play, Pause, Next, Previous, Shuffle, Loop Mode.
- **اسلایدر نوار پیشرفت (Seek Bar):** اسلایدر با قابلیت عقب/جلو بردن زمان و نمایش دقیق زمان گذشته و زمان کل.
- **پخش در پس‌زمینه (Background Playback):** تداوم بی‌وقفه پخش صدا هنگام خروج از اپلیکیشن یا خاموش شدن صفحه نمایش با `just_audio_background`.
- **کنترل اعلان سیستم‌عامل (Media Notification):** نمایش کاور آهنگ، نام خواننده و قطعه در نوار نوتیفیکیشن اندروید و صفحه قفل دستگاه با دکمه‌های کنترلی Play/Pause و جابجایی قطعات.
- **مینی‌پلیر شناور (Mini Player):** نمایش نوار مینی‌پلیر در پایین تمام صفحات در زمان پخش با نمایش وضعیت و پیشرفت ترانه و قابلیت باز کردن پلیر تمام‌صفحه با تپ کردن.
- **پلیر تمام‌صفحه (Full Screen Player):** رابط کاربری با انیمیشن چرخش صفحه گرامافون هنگام پخش، اسلایدر پخش، دکمه لایک و کنترل‌های کامل.

### ۴. رابط کاربری و تجربه کاربری (UI/UX)
- طراحی کاملاً دارک (Dark Theme) الهام‌گرفته از اسپاتیفای با رنگ سبز اختصاصی `#1DB954`.
- چیدمان کاملاً راست‌چین و بومی (RTL) به زبان فارسی.
- صفحه خوش‌آمدگویی و معرفی اپلیکیشن (Onboarding) صرفاً در اولین اجرای پس از نصب با ذخیره‌سازی وضعیت.
- صفحه اسپلش (Splash Screen) با انیمیشن ورود و بررسی خودکار اعتبار نشست کاربر.
- صفحات اصلی: خانه (Home)، جست‌وجو (Search)، کتابخانه (Library) با تب‌های پلی‌لیست و علاقه‌مندی‌ها، و پروفایل کاربری.

## 🚀 راهنمای راه‌اندازی و اجرا

### پیش‌نیازها
- **Flutter SDK:** نسخه 3.24 یا بالاتر (تست شده روی Flutter 3.47 / Dart 3.13)
- **Android SDK:** حداقل `minSdkVersion = 23`
- اتصال اینترنت جهت برقراری ارتباط با وب‌سرویس

### مراحل اجرا
۱. دریافت پکیج‌های پروژه:
```bash
flutter pub get
```

۲. اجرای اپلیکیشن روی دستگاه یا شبیه‌ساز اندروید:
```bash
flutter run
```

## 📱 ساخت فایل نصبی بهینه (APK)

برای ساخت خروجی نهایی بهینه مخصوص معماری پردازنده‌های رایج موبایل (`arm64-v8a`) با کمترین حجم ممکن، دستور زیر را اجرا کنید:

```bash
flutter build apk --release --split-per-abi
```

فایل خروجی بهینه شده در مسیر زیر قرار می‌گیرد:
```
build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```
